# «Нескучные выходные» — сайт клуба поездок

Сайт туристического клуба: поездки выходного дня и короткие туры с ночёвкой
по Краснодарскому краю. **Краснодар · Лабинск · Майкоп · Ханская ·
Белореченск · Курганинск · Гиагинская · Дондуковская**

Собран на Django 6 + Wagtail 7, вся вёрстка — Tailwind 3, интерактив — Alpine.js.

---

## Что внутри

| Слой | Технология |
|------|-----------|
| Backend | Python 3.13, Django 6.0, Wagtail 7.4 |
| БД | SQLite (dev) → PostgreSQL (prod) |
| Статика | WhiteNoise, django-tailwind, Pillow, Wagtail Images (авто-WebP) |
| Frontend | Tailwind 3, Alpine.js 3 |

## Быстрый старт

```bash
pip install -r requirements.txt

# .env уже создан для локальной разработки
npm install --prefix theme/static_src

python manage.py migrate
python manage.py createsuperuser          # логин для /cms/
python manage.py placeholders             # бирюзовые заглушки под фото
python manage.py fetch_stock_photos       # реальные фото со свободных лицензий
python manage.py seed                     # 8 направлений + 288 выездов
python manage.py tailwind build           # сборка CSS
python manage.py runserver
```

Сайт: <http://127.0.0.1:8000/> · Админка: <http://127.0.0.1:8000/cms/>

## Ключевые решения

**Туров нет.** Единица каталога — **направление**, у него есть расписание
**выездов**. Вложенности «тур → направление» не строим.

**Палитра.** Бирюза доминирует, коралл отдан конверсии (кнопки, цены),
солнечный жёлтый — бейджам. Один источник значений — `theme/static_src/tailwind.config.js`,
те же токены продублированы в `static/css/admin.css`, чтобы публичная часть
и админка не разъехались.

**Контраст — не украшение, а требование.** Белый текст на `#00C2B0` даёт
2.25:1, поэтому в кнопках используется `#00857A` (4.5:1), а текстом кораллом
по белому — `#C93C1B` (4.6:1). Подробный расчёт — в `DESIGN_PROMPT.md` §2.1.

**Админка рассчитана на обычного человека:** русские подписи вместо
технических терминов, подсказки с примерами, чек-лист готовности с
процентами, запрет публикации без обложки/цены/расписания, отдельный экран
расписания выездов, три колонки в редакторе с живым предпросмотром.

## Фотографии

Три источника, приоритет сверху вниз:

1. **Реальные фото клиента** — загрузить в админке, они всегда лучше стоков.
2. **Стоки со свободными лицензиями** — `fetch_stock_photos` тянет Openverse
   или Wikimedia Commons, оставляет только CC0 / Public Domain / CC BY / CC BY-SA
   (NC и ND исключены), режет под нужные пропорции, отсеивает дубли по
   содержимому и старые гравюры/журналы. Атрибуция пишется в
   `media/stock/sources.json` — её нужно вывести на странице, если фото останутся.
3. **Бирюзовые плейсхолдеры** — `placeholders`, чтобы сайт не выглядел сломанным,
   пока фото нет.

Автозагруженные стоки — это заглушки под конкретные места, а не фотографии
Краснодарского края. Перед запуском их нужно заменить.

## Деплой

```bash
DEBUG=False
ALLOWED_HOSTS=example.ru
CSRF_TRUSTED_ORIGINS=https://example.ru
WAGTAILADMIN_BASE_URL=https://example.ru
SECRET_KEY=<из generate_secret_key>
```

При `DEBUG=False` автоматически включаются secure-куки и HSTS.
Статика собирается `python manage.py collectstatic --noinput` и раздаётся
через WhiteNoise.
